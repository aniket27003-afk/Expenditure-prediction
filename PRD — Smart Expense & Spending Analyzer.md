# Smart Expense & Spending Analyzer

## 1. Product Overview

An AI-powered expense analysis application that uses an **LLM to understand transactions, categorize expenses, detect spending patterns, and generate personalized insights**.

No separate ML model training is required.

## 2. Problem

Users receive transactions in messy formats such as:

```text
UPI-UBER-TRIP-284
SWIGGY ORDER 8472
AMAZON PAY INDIA
IRCTC TXN 93821
```

Understanding and organizing these transactions manually is inconvenient.

## 3. Goal

Turn raw transaction data into structured expenses and provide useful, natural-language financial insights.

## 4. Core Features

### A. Add Expenses

User enters:

- Amount
- Description
- Date
- Payment method

### B. LLM-Based Expense Understanding

The LLM extracts:

```json
{
  "merchant": "Uber",
  "category": "Transportation",
  "amount": 280
}
```

It can also understand ambiguous or messy descriptions.

### C. Automatic Categorization

Categories:

```text
Food
Transportation
Shopping
Bills
Entertainment
Healthcare
Education
Travel
Investment
Other
```

### D. Dashboard

Show:

- Total spending
- Monthly spending
- Category-wise spending
- Top merchants
- Recent transactions
- Spending trends

These values are calculated with **Python/SQL**, not generated by the LLM.

### E. AI Spending Analysis

The LLM receives the user's summarized spending data and generates insights such as:

> "Your food spending increased compared with last month."

> "Transportation is one of your largest expense categories."

> "You made unusually high spending on shopping this month."

### F. AI Anomaly Detection

Instead of training an anomaly-detection model, send relevant transaction history/statistics to the LLM and ask it to identify potentially unusual transactions.

Example:

```text
Normal transactions:
₹300
₹450
₹700
₹500

New transaction:
₹12,500

→ Potentially unusual transaction
```

### G. AI Spending Forecast

The LLM can analyze historical monthly spending and provide an estimated upcoming expense range.

Example:

```text
January   ₹18,000
February  ₹20,500
March     ₹21,000
April     ₹22,300

→ Estimated May spending: ~₹22,000–₹24,000
```

For a college project, this can be presented as an **AI estimate**, not a guaranteed financial forecast.

## 6. Technology Stack

**Frontend:** React.js

**Backend:** Python + FastAPI

**Database:** PostgreSQL

**AI:** LLM API

**Data processing:** Python + Pandas

**Charts:** Recharts / Plotly

**Deployment:** Vercel + Render/Railway or equivalent

## 7. LLM Responsibilities

The LLM handles:

- Transaction understanding
- Merchant extraction
- Expense categorization
- Ambiguous transaction interpretation
- Spending-pattern analysis
- Anomaly identification
- Forecast/estimate generation
- Personalized recommendations
- Natural-language explanations

## 8. Non-LLM Responsibilities

Python/SQL handles:

- Storing transactions
- SUM/AVG calculations
- Monthly totals
- Category totals
- Date filtering
- Database queries
- Authentication
- API requests
- Dashboard data

This keeps numerical calculations deterministic instead of asking the LLM to calculate them.

## 12. Final Project Title

**"AI-Powered Smart Expense & Spending Analyzer Using LLM-Based Transaction Understanding and Personalized Financial Insights"**

### Key Design Decision

**No custom ML model training. No NLP model training. No separate forecasting/anomaly model.**

The project uses:

**LLM → intelligence and reasoning**

**Python/SQL → reliable calculations and data processing**

**PostgreSQL → persistent storage**

This makes the project substantially faster to build while still demonstrating meaningful AI integration.
